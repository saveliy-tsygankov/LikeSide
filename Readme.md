# LakeSide — сервис бронирования отелей

Многостраничный демо-проект сервиса бронирования отелей по России.
## Демо

🔗 **Live:** https://saveliy-tsygankov.github.io/LikeSide/

## Возможности

- Главная с hero-поиском, слайдером направлений, топом отелей, отзывами и FAQ
- Каталог отелей с фильтрами (цена, звёзды, удобства), сортировкой и живым поиском
- Страница отеля: галерея, удобства, карта OpenStreetMap, виджет бронирования
- Пошаговое бронирование: даты → данные гостя → подтверждение
- Вход и регистрация с валидацией форм
- Тёмная и светлая темы с сохранением в localStorage
- Прелоадер, reveal-анимации, «наверх», адаптивная вёрстка

## Стек

- React 18 (UMD)
- jQuery 3.7 (анимации, скролл-эффекты)
- Babel Standalone (транспиляция JSX в браузере)
- Font Awesome 6
- Google Fonts (Inter, JetBrains Mono, Playfair Display)
- OpenStreetMap embed для карт
